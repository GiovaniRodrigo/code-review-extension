# Git Code Review 4.1.0 — Real RAG & Project Chat

## Objetivo

Evoluir o uso de RAG e chat para um fluxo mais explícito para code reviewers.

## Implementado

- `Code Review: Open RAG Context Explorer`
- Painel visual para branch, workspace, contexto e rastreabilidade
- Ações diretas para indexar RAG, buscar contexto e abrir Project Chat
- Linguagem de produto orientada a fontes/contexto usado pelo chat

## Próximo backend necessário

RAG incremental real por hash de arquivo, citações por chunk e ranking contextual persistido.
