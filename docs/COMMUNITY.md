# Community Edition

## Filosofia

A Community Edition é local-first, offline-first e privacy-first.

## Recursos

- review manual;
- sessões locais;
- dashboard local;
- AST Builder;
- Graph local;
- Analyzer local;
- IA local ou integrada ao VS Code;
- automações locais;
- comentários sugeridos por IA com aprovação humana.

## IA Community

A IA é fornecida pelo usuário. Integrações planejadas:

- Ollama;
- LM Studio;
- llama.cpp;
- Continue;
- GitHub Copilot quando houver interoperabilidade disponível;
- comandos de terminal;
- API local customizada.

## Fidelidade visual

A interface deve mostrar:

- selo Community;
- status “Rodando localmente”;
- IA ativa;
- aviso de que o código permanece na máquina;
- recursos premium bloqueados sem atrito excessivo.
