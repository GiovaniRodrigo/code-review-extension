# Enterprise Foundation — 4.0.0

## Objetivo

Adicionar a base Enterprise de governança, segurança, auditoria, SSO/RBAC, políticas de IA e self-hosted readiness.

## Entregas

| Recurso | Entrega |
|---|---|
| Enterprise Governance | Tela central para governança corporativa |
| SSO | Configuração local-ready para SAML/OIDC |
| RBAC | Role local por workspace: admin, reviewer ou viewer |
| Audit Logs | Registro e exportação local de ações de governança |
| AI Policies | Políticas locais de uso de IA e cloud |
| Self-hosted Bundle | Geração de documento de readiness self-hosted |

## Limite conhecido

SSO real, RBAC multiusuário, tenant management, billing e cloud sync exigem backend Enterprise. O VSIX 4.0.0 entrega a camada de produto/UX e readiness local.
