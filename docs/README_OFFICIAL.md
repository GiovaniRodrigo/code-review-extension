# Documentação Oficial

Arquivos oficiais do projeto:

- README.md
- docs/ARCHITECTURE.md
- docs/ROADMAP.md
- docs/BUSINESS_RULES.MD
- docs/PERFORMANCE.md
- docs/README_OFFICIAL.md

Arquivos contendo FIXES, SUMMARY, ALIGNMENT ou NOTES são históricos.


## Feedback de usuário

O projeto exige feedback completo para ações assíncronas, incluindo carregamento, sucesso, erro, vazio e progresso. A especificação oficial está em `docs/USER_FEEDBACK_UX.md`.
