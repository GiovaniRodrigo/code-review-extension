# Camadas e Setores de Qualidade de Software

Esta pasta organiza a literatura de [categorias](../categorias) por camadas do software e setores envolvidos no ciclo de desenvolvimento.

O objetivo é deixar claro:

* quais responsabilidades pertencem a cada camada técnica,
* quais setores participam da qualidade,
* quais metodologias e estratégias se aplicam,
* quais ferramentas apoiam cada contexto,
* quais modelos de gestão ajudam a governar qualidade, risco e entrega.
