# Premium Edition

## Filosofia

A Premium Edition adiciona colaboração, banco remoto, IA integrada, Graph persistente e analytics organizacional.

## Níveis

### Premium Starter

- sync remoto;
- banco cloud;
- IA cloud básica;
- histórico remoto;
- comentários IA online.

### Premium Team

- múltiplos revisores;
- dashboard compartilhado;
- automações compartilhadas;
- Graph compartilhado;
- analytics de equipe.

### Premium Enterprise

- SSO;
- RBAC;
- auditoria;
- compliance;
- self-hosted;
- políticas organizacionais;
- Graph organizacional;
- IA avançada.

## Fidelidade visual

A UI deve mostrar:

- selo do plano;
- status de sincronização;
- presença colaborativa;
- IA cloud ativa;
- analytics disponível conforme plano.
