# Pro UX Polish — 2.6.0

## Objetivo

A versão 2.6.0 aproxima a extensão do wireframe oficial e reduz dependência da Command Palette.

## Entregas

| Tela | Entrega |
|---|---|
| Dashboard | Entrada visual para Start Review, provider, RAG, reports, Team e Enterprise |
| Findings | Fluxo HITL mantido com ações de approve, reply, copy, refactor e export |
| Diagnostics | Mantido como check de prontidão antes de review |
| Provider Setup | Nova tela visual `Open Provider Setup` para Mock, Ollama, OpenAI, Claude, Gemini e Custom endpoint |
| Quality Report | Nova workspace page `Open Quality Report Workspace` |
| PR Summary | Nova workspace page `Open PR Summary Workspace` |

## Critério de aceite

O reviewer consegue iniciar o fluxo principal pela interface visual, com acesso aos módulos de provider, report e planos sem decorar comandos.
