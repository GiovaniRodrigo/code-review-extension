# Reports & Review Intelligence — 2.9.0

## Objetivo

Agrupar relatórios, histórico e inteligência de revisão para apoiar a decisão do code reviewer.

## Entregas

| Recurso | Entrega |
|---|---|
| Review Intelligence | Nova tela com métricas e decisão de review |
| Quality Report | Workspace visual com score, severidade e recomendações |
| PR Summary | Workspace visual para gerar resumo de PR |
| History | Integração com o histórico local já existente |
| Export | Markdown e PDF permanecem disponíveis |

## Critério de aceite

O reviewer consegue gerar artefatos profissionais e acompanhar a qualidade da sessão sem depender apenas do chat.
