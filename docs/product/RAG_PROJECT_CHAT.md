# RAG + Project Chat — 2.7.0

## Objetivo

Transformar RAG e Project Chat em recursos operacionais para code reviewers.

## Entregas

| Recurso | Entrega |
|---|---|
| RAG Manager | Tela visual para indexar, limpar e pesquisar contexto |
| Project Chat | Comando para focar o chat da extensão |
| Contexto por branch | O fluxo considera branch atual e sessão ativa |
| Integração com reports | PR Summary e Quality Report passam a ter entrada visual ligada ao contexto |

## Limite conhecido

A indexação e o chat usam a infraestrutura local já existente na extensão. Sincronização cloud de contexto entra como evolução Team/Enterprise.
