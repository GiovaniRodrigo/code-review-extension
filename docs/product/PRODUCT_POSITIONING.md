# Product Positioning

## Produto

**Git Code Review** é um workspace de governança de code review para code reviewers dentro do VS Code.

## Público-alvo oficial

```text
Code reviewers
```

## Categoria

```text
Code Review Governance Workspace for VS Code
```

## Headline

```text
Code review for reviewers, inside your IDE.
```

## Subheadline

```text
Use Git context, AI assistance, RAG and Human-in-the-Loop findings to decide whether a change is ready to approve.
```

## Promessa central

Ajudar code reviewers a decidir, com mais contexto e menos retrabalho, se uma mudança de código está pronta para ser aprovada.

## O que o produto é

| Definição | Descrição |
|---|---|
| Workspace de review | Centraliza sessão, findings, comentários, Git e diagnósticos |
| Ferramenta para reviewers | Otimizada para quem revisa código, não apenas para quem escreve código |
| IDE-first | O fluxo acontece dentro do VS Code |
| Local-first | Funciona localmente com Ollama/mock e histórico local |
| AI-assisted | IA ajuda, mas não decide |
| Human-in-the-Loop | Reviewer aprova, rejeita, comenta e aplica decisões |
| RAG-enabled | Usa contexto do repositório para melhorar análise |

## O que o produto não é

| Não é | Motivo |
|---|---|
| Apenas chatbot | O centro é a Review Session, não conversa solta |
| Apenas lint | Consolida Git, IA, histórico, comentários e governança |
| Substituto do reviewer | A decisão humana é obrigatória |
| Ferramenta cloud-only | Community deve funcionar localmente |
| Apenas extensão visual | Deve entregar fluxo de decisão de review |

## Diferenciais

| Diferencial | Valor |
|---|---|
| Code reviewer-first | Produto desenhado para quem aprova ou bloqueia mudanças |
| Git context | Review conectado a branch, PR, diff e workspace |
| HITL findings | Findings precisam de decisão humana |
| RAG local/cloud | Contexto do repositório melhora qualidade da análise |
| Score de Qualidade | Ajuda a priorizar risco e prontidão |
| Diagnósticos integrados | Consolida sinais técnicos em uma visão |
| Planos progressivos | Community, Pro, Team e Enterprise |
