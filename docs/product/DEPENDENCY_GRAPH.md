# Dependency Graph — 2.8.0

## Objetivo

Adicionar uma visualização arquitetural para que code reviewers entendam dependências, ciclos e impacto de findings.

## Entregas

| Recurso | Entrega |
|---|---|
| Graph View | Comando `Open Dependency Graph` foca a view de grafo |
| Pacote/arquivo | Base para navegação por módulos do workspace |
| Findings overlay | Preparado para relacionar findings e hotspots |
| Arquitetura | Suporte a análise de impacto e ciclos |

## Critério de aceite

O reviewer consegue acessar o grafo sem sair do produto e usá-lo como apoio para revisão arquitetural.
